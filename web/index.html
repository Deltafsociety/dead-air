DEADAIR

Offline and Intranet Nostr Station

System Overview

DEADAIR is a lightweight, zero-dependency terminal user interface (TUI) communication station built in Rust. It is engineered specifically for digital blackouts, local mesh networks, and national intranet cutoffs where international internet traffic is severed.

It uses the decentralized Nostr protocol without requiring any paid servers, centralized accounts, or domain registries. Your cryptographic identity is generated and stored locally on your machine.

Live Terminal Interface and Workflow
National Intranet Architecture

During nationwide network shutdowns (such as the National Information Network scenario in Iran), foreign servers hosted in Europe or the US are blocked, rendering standard communication apps useless. However, domestic routing between local ISPs and cities remains operational.

  • Domestic IP Detection: Automatically discovers your routable network address. Hit /share or [s] to get your station address: ws://<your_ip>:4869 [handle].
  • Persistent Relay Bookmarks: Manage trusted domestic nodes across cities via /bookmark add ws://<peer_ip>:4869 [name]. Connect all saved relays instantly with [b].
  • Embedded Relay: Press [r] to start an internal WebSocket relay on 0.0.0.0:4869. Other computers across Iran can connect directly to your domestic IP.
  • Intranet UDP Discovery: On local Wi-Fi or LAN networks, DEADAIR discovers neighbor stations automatically on UDP port 48690.
  • Offline Outbox: Notes drafted while completely disconnected are queued in local storage and broadcast automatically the instant a peer or relay connects.
One-Line Install (Linux and macOS)

Run the following command in your terminal to install and launch deadair from anywhere:

curl -fsSL https://raw.githubusercontent.com/deltafsociety/dead-air/master/install.sh | bash

Commands Reference
Command Description
/share Display your domestic address and handle for sharing with peers.
/ip Re-run domestic network IP address detection.
/name <handle> Set your station handle and broadcast a signed metadata event to all relays.
/bookmark add <url> [name] Bookmark a domestic relay and connect.
/bookmark remove <key> Remove a relay from domestic bookmarks.
/bookmark connect Reconnect to all saved domestic relay bookmarks.
/relay add <url> Connect to an intranet or internet relay (and auto-bookmark).
/relay public Toggle connection to global public relays (Damus, nos.lol, Primal).
/tab [station|public] Switch between DEADAIR Station chat and Public Social Mesh tabs.
/like Like (❤️ Nostr Kind 7 reaction) the currently selected note in the public feed.
/reply <msg> Send a threaded reply (Kind 1 with 'e' & 'p' tags) to the selected note.
/clear Clear messages in active timeline tab.
/help Show available command summary.
Key Action
Tab or t Switch between DEADAIR Station and Public Social Mesh tabs.
1 or 2 Jump directly to Station tab (1) or Public Mesh tab (2).
j / Down Browse newer posts in Public feed (pauses live stream).
k / Up Browse older posts in Public feed (pauses live stream).
g or Home Resume live streaming feed in Public tab.
l or L Like (❤️ Kind 7 reaction) the selected public note.
r (Public tab) Reply (💬 threaded Kind 1 note) to the selected public post.
r or F2 (Station tab) Toggle embedded relay on or off (port 4869).
p Toggle public internet relays.
c Clear local timeline screen.
q Quit DEADAIR.
Quick Start
# Direct install via Cargo
cargo install --git https://github.com/deltafsociety/dead-air.git

# Or build from source
git clone https://github.com/deltafsociety/dead-air.git
cd dead-air
cargo build --release
./target/release/deadair
معرفی سامانه

نرم‌افزار DEADAIR یک ابزار ارتباطی ترمینال متنی (TUI) سبک و بدون وابستگی است که با زبان راست (Rust) توسعه داده شده است. این سامانه منحصرا برای شرایط قطع کامل اینترنت، شبکه‌های محلی (مش) و محدودیت به شبکه ملی اطلاعات (اینترانت) طراحی شده است.

این ابزار از پروتکل غیرمتمرکز نوستر (Nostr) استفاده می‌کند و هیچ‌گونه وابستگی به سرورهای پولی، ثبت‌نام، شماره تماس، ایمیل یا دامنه‌های اینترنتی ندارد. کلیدهای رمزنگاری شما به صورت محلی روی دستگاه خودتان ایجاد و ذخیره می‌شوند.

نمای زنده خط فرمان و جریان کار
عملکرد در شرایط اینترانت ملی

هنگامی که دسترسی به اینترنت بین‌الملل قطع می‌شود، سرورهای خارجی از دسترس خارج شده و پیام‌رسان‌های معمولی متوقف می‌شوند. با این حال، ارتباطات داخلی بین ارائه‌دهندگان اینترنت داخلی و شهرهای مختلف برقرار باقی می‌ماند.

  • تشخیص خودکار IP داخلی: سامانه آدرس قابل اتصال شما را پیدا می‌کند. با کلید [s] یا دستور /share مشخصات ایستگاه را برای دیگران بفرستید: ws://<ip>:4869 [نام].
  • مدیریت نشانک‌های رله‌های داخلی: ذخیره و سازماندهی رله‌های سراسر کشور با دستور /bookmark add ws://<ip>:4869 [نام]. اتصال همزمان با کلید [b].
  • رله داخلی تعبیه‌شده: با کلید [r] سرور رله خود را روی پورت 4869 فعال کنید تا افراد در شهرهای دیگر به شما متصل شوند.
  • کشف خودکار در شبکه محلی: دستگاه‌ها روی وای‌فای یا LAN از طریق پورت UDP 48690 یکدیگر را به شکل خودکار پیدا می‌کنند.
  • صندوق پیام‌های آفلاین: پیام‌های نوشته‌شده در زمان قطعی کامل در سیستم ذخیره شده و پس از اولین اتصال ارسال می‌شوند.

دستورات ترمینال
دستور توضیحات
/share نمایش آدرس ایستگاه داخلی جهت اشتراک‌گذاری با دیگران.
/ip تشخیص مجدد آدرس IP شبکه داخلی.
/name <نام> تنظیم نام نمایشی و انتشار مشخصات هویتی برای سایر کاربران.
/bookmark add <آدرس> [نام] ذخیره رله داخلی در نشانک‌ها و اتصال به آن.
/bookmark remove <شناسه> حذف رله از فهرست نشانک‌ها.
/bookmark connect اتصال مجدد به تمامی نشانک‌های ذخیره‌شده.
/relay add <آدرس> افزودن آدرس رله جدید (و ذخیره خودکار در نشانک‌ها).
/relay public اتصال یا قطع اتصال به رله‌های رایگان اینترنت جهانی.
/tab [station|public] جابه‌جایی میان برگه گفتگوهای DEADAIR و برگه شبکه اجتماعی رله‌های عمومی.
/like پسندیدن (واکنش نوستر Kind 7) یادداشت عمومی انتخاب‌شده.
/reply <پیام> ارسال پاسخ رشته‌ای (Kind 1 با تگ‌های ارجاع) به پست انتخاب‌شده.
/clear پاک کردن پیام‌های برگه فعال کنونی.
/help نمایش راهنمای دستورات.
کلید عملکرد
Tab یا t جابه‌جایی سریع میان برگه ایستگاه DEADAIR و شبکه اجتماعی رله‌های عمومی.
1 یا 2 پرش مستقیم به برگه ایستگاه (1) یا برگه شبکه عمومی (2).
j / Down حرکت به سمت پست‌های تازه‌تر در برگه عمومی (مکث جریان زنده).
k / Up حرکت به سمت پست‌های قدیمی‌تر در برگه عمومی (مکث جریان زنده).
g یا Home از سرگیری جریان زنده پیام‌ها در برگه عمومی.
l یا L لایک کردن (❤️ واکنش Kind 7) پست عمومی انتخاب‌شده.
r (برگه عمومی) ارسال پاسخ به پست انتخاب‌شده (💬 پاسخ رشته‌ای).
r یا F2 (برگه ایستگاه) روشن یا خاموش کردن رله داخلی روی پورت 4869.
p تغییر وضعیت رله‌های عمومی اینترنت.
c پاک کردن پیام‌های صفحه نمایش.
q خروج از برنامه.
